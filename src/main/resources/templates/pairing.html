Why a provider's base URL is this one host and a path

Every provider of this simulator answers on the one host above. What differs between them is the path their contract is published on, so the base URL of a provider is that host and that path and never a host of its own. An application that must keep calling an address of its own reaches this simulator through a route alias instead, below.

Why this is a URL and not a code to scan

One URL, and nothing else. It carries this simulator's public base, this provider and this test run, so a phone that reads it opens this same screen on the phone. It is printed rather than drawn as a code: this build carries no encoder it could prove correct, and a symbol nothing can decode back is a picture rather than a payload.
