What is in this document, and what is deliberately not

Copy it into a bug report. It carries the run's setup, which an import writes back, and the evidence of this one payment, which no import writes: the trail rows of every exchange this simulator served for it with the sanitized headers and body of each, the callbacks with their attempts, the effective simulator clock and the object's state and ledger.

No value this provider declares secret is in it, and each account names the secret fields it leaves out. An import is given those separately in the box below.

Take a bundle back

What an import preserves, what it reads only, and what a dry run differs in

A dry run and a real import answer the same report, and differ only in whether it was applied. The evidence half is read by neither, so a bundle taken back leaves the target run holding the setup and no trail row, no callback and no payment of the run it came from.
