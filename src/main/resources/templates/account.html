The fields below are 's own, in 's own names, and this screen asked the provider what an account of it would need rather than holding a list of its own. A value left empty is not sent, so the provider answers with whatever it publishes as the default for that field, and a field the provider requires is refused by name.

Naming an account that this test run already configures replaces that account whole. Naming one it does not adds it and leaves the others exactly as they are, so a second account costs nothing of the first and no secret of the first is retyped here.
