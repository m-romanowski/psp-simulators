Where specificity and arrival come from

Specificity is counted from the facts a rule narrows on and arrival is the column the store gave it, so neither is a field either rule was written with. They are here because they decide which of two matching rules the engine takes.

What writing a copy leaves behind

What each box already holds, and what an emptied one means

Every box holds what the rule it was copied from says, so change the one thing that differs and leave the rest alone. A box emptied narrows nothing. The copy is written through the same admission as any other rule, so a provider that cannot perform what you changed refuses it and writes nothing.
