What the story told the simulator

  • A Stripe account keyed by a secret key of this run alone, its webhooks aimed at this shop and signed, and the clock pinned to 2026-09-15T10:00:00Z. See it configured
  • A saved Visa ending 4242, pm_1, the card checkout pays with. See the saved card
  • A scenario rule scn_1: every capture of this run is refused as expired_card. See the rule

Steps

  1. Buy the espresso machine: open the product, go to checkout and pay with the saved card. The shop creates a PaymentIntent with capture_method=manual and confirms it, so the money is held, not taken. Go to the product
  2. Capture the order on the order page. Expect Stripe to refuse it as expired_card, and the simulator's trail to name the rule that decided it. Expect Stripe to accept it.
  3. Let Stripe tell the shop. The simulator sends a Stripe event only when asked to, so the story asks it, through the control API, to send payment_intent.succeeded. It arrives signed at the shop's webhook endpoint, which verifies the signature and lists it on the order page.
